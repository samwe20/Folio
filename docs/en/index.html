Folio

A calm Markdown editor for Windows. The writing experience takes cues from iA Writer; for backlinks, Folio borrows the idea from Obsidian — it's its own app, not a substitute for those tools.

Download Folio 1.0.7 (Windows) Latest release Source code

Why Folio

  • Inspired by iA Writer Focused writing — Focus Mode, typewriter scrolling, typography, and light/dark themes for calm drafting.
  • Inspired by backlinks From Obsidian, Folio mainly takes the backlink idea — [[wiki links]], completion, and panels for incoming and outgoing links. No graph, no plugins.
  • Folder on disk, your sync The library is a plain folder of .md files. There is no built-in sync — put the folder in OneDrive, iCloud Drive, or another synced location and your files follow your cloud.
  • Windows Desktop with Tauri 2. UI in English / Czech — your notes stay in whatever language you write them.

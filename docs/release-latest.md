## Folio 1.0.8 — Windows

**Instalátor:** [Folio_1.0.8_x64-setup.exe](https://github.com/samwe20/Folio/releases/download/folio-1.0.8/Folio_1.0.8_x64-setup.exe)  
**Požadavky:** Windows 10 nebo 11 (WebView2)

### Co je nového oproti 1.0.7

- **Menu ☰** — verze aplikace, ruční kontrola aktualizací, export knihovny (ZIP) a poznámky (.md), přepínače vzdálených obrázků v náhledu.
- **Obrázky (Windows)** — spolehlivější přetažení z Průzkumníka; po uložení do `assets/` se opraví rozbitý text v poznámce (`![](assets/…)`).
- **Ukázkový tutoriál** — anglická demo knihovna; migrace staré české startovní sady (i vedle vlastních poznámek).
- **První spuštění** — výchozí jazyk rozhraní **English** (Čeština jedním klikem v toolbaru).
- **Aktualizace** — po ruční kontrole jasná hláška *žádná nová aktualizace* (CS/EN) a správně velké tlačítko *Rozumím*.

### Instalace / upgrade z 1.0.7

1. Stáhněte `Folio_1.0.8_x64-setup.exe` ([release folio-1.0.8](https://github.com/samwe20/Folio/releases/tag/folio-1.0.8)).
2. Spusťte instalátor (knihovna v Dokumentech zůstane).
3. Nebo v 1.0.7: **☰ → Zkontrolovat aktualizace → Stáhnout**.

**Smart App Control:** [windows-smart-app-control.md](https://github.com/samwe20/Folio/blob/main/docs/windows-smart-app-control.md)

## Folio 1.0.8 — Windows (English)

**Installer:** [Folio_1.0.8_x64-setup.exe](https://github.com/samwe20/Folio/releases/download/folio-1.0.8/Folio_1.0.8_x64-setup.exe)  
**Requirements:** Windows 10 or 11 (WebView2)

### What's new since 1.0.7

- **☰ menu** — version, manual update check, library/note export, remote image toggles in preview.
- **Images (Windows)** — reliable Explorer drag-and-drop; fixes in-note markdown after `assets/` save.
- **Sample tutorial** — English starter library; migrates legacy Czech-only demo set.
- **First launch** — default UI language **English** (switch to Čeština anytime).
- **Updates** — clear *No update available* message and fixed *OK* button sizing.

### Install / upgrade from 1.0.7

1. Download `Folio_1.0.8_x64-setup.exe` ([folio-1.0.8](https://github.com/samwe20/Folio/releases/tag/folio-1.0.8)).
2. Run the installer (your library is kept).
3. Or from 1.0.7: **☰ → Check for updates → Download**.

**Smart App Control:** [windows-smart-app-control.md](https://github.com/samwe20/Folio/blob/main/docs/windows-smart-app-control.md)

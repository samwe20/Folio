## Folio 1.0.5 — Windows

**Instalátor:** [Folio_1.0.5_x64-setup.exe](https://github.com/samwe20/Folio/releases/download/folio-1.0.5/Folio_1.0.5_x64-setup.exe)  
**Požadavky:** Windows 10 nebo 11 (WebView2 — na Windows 11 obvykle už nainstalovaný)

### Co je nového

- **Jazyk rozhraní** — v liště přepínač **English / Čeština** (text poznámek zůstává ve vašem jazyce).
- **Zaoblené ovládací prvky** — konzistentnější vzhled seznamu souborů, polí a tlačítek.
- **Veřejné repo** — dokumentace, screenshoty a open-source kód na GitHubu.

### Instalace

1. Stáhněte `Folio_1.0.5_x64-setup.exe` z odkazu výše (nebo ze [stránky release](https://github.com/samwe20/Folio/releases/tag/folio-1.0.5)).
2. Spusťte instalátor (samostatný NSIS setup, ne zip).
3. Po spuštění Folio vytvoří knihovnu v `Dokumenty/Folio/Library` — nebo zvolte **Otevřít knihovnu** a vyberte složku s `.md` soubory (včetně OneDrive / iCloud Drive ve Windows).

### Tipy

- **Focus Mode** — celá obrazovka pro psaní; volitelný typewriter.
- **`[[Wiki odkazy]]`** — dvojklik nebo dlouhý stisk pro otevření; panel zpětných odkazů vpravo.
- **iPhone bez Macu** — použijte web / PWA: [docs/web-pwa.md](https://github.com/samwe20/Folio/blob/main/docs/web-pwa.md)

## Folio 1.0.5 — Windows (English)

**Installer:** [Folio_1.0.5_x64-setup.exe](https://github.com/samwe20/Folio/releases/download/folio-1.0.5/Folio_1.0.5_x64-setup.exe)  
**Requirements:** Windows 10 or 11 (WebView2 — usually preinstalled on Windows 11)

### What's new

- **UI language** — toolbar toggle **English / Čeština** (your note content stays whatever you write).
- **Rounded controls** — cleaner file list, inputs, and buttons.
- **Public repository** — docs, screenshots, and source on GitHub.

### Install

1. Download `Folio_1.0.5_x64-setup.exe` from the link above (or the [release page](https://github.com/samwe20/Folio/releases/tag/folio-1.0.5)).
2. Run the standalone NSIS installer.
3. On first launch Folio uses `Documents/Folio/Library` by default — or use **Open library** to pick any folder of `.md` files (including OneDrive / iCloud Drive on Windows).

### Tips

- **Focus Mode** — fullscreen writing; optional typewriter scrolling.
- **`[[Wiki links]]`** — double-click or long-press to open; backlinks panel on the right.
- **iPhone without a Mac** — web / PWA: [docs/web-pwa.md](https://github.com/samwe20/Folio/blob/main/docs/web-pwa.md)

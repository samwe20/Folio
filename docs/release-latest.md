## Folio 1.0.9 — Windows

**Instalátor:** [Folio_1.0.9_x64-setup.exe](https://github.com/samwe20/Folio/releases/download/folio-1.0.9/Folio_1.0.9_x64-setup.exe)  
**Požadavky:** Windows 10 nebo 11 (WebView2)

### Co je nového

- **Anglický tutoriál** — tlačítko *Start with sample library* vždy otevře `Welcome to Folio.md` a doplní anglickou sadu; staré české startovní soubory (`Vítejte ve Folio.md`, …) se nahradí i když máte vedle vlastní poznámky.
- **První spuštění** — výchozí jazyk rozhraní je **English** (Čeština zůstává jedním klikem v toolbaru).
- **Updater UI** — tlačítko *Rozumím* / *Later* má správnou velikost a klikací plochu.

### Instalace

1. Stáhněte `Folio_1.0.9_x64-setup.exe` ([release folio-1.0.9](https://github.com/samwe20/Folio/releases/tag/folio-1.0.9)).
2. Spusťte instalátor; knihovna v Dokumentech zůstane.

**Smart App Control:** [windows-smart-app-control.md](https://github.com/samwe20/Folio/blob/main/docs/windows-smart-app-control.md)

## Folio 1.0.9 — Windows (English)

**Installer:** [Folio_1.0.9_x64-setup.exe](https://github.com/samwe20/Folio/releases/download/folio-1.0.9/Folio_1.0.9_x64-setup.exe)  
**Requirements:** Windows 10 or 11 (WebView2)

### What's new

- **English tutorial** — *Start with sample library* always opens `Welcome to Folio.md` and installs the English starter set; legacy Czech starter files are replaced even when you already have your own notes in the folder.
- **First launch** — default UI language is **English** (switch to Čeština anytime from the toolbar).
- **Updater UI** — *OK* / *Later* buttons sized correctly (no 36px icon hitbox).

### Install

1. Download `Folio_1.0.9_x64-setup.exe` ([release folio-1.0.9](https://github.com/samwe20/Folio/releases/tag/folio-1.0.9)).
2. Run the installer; your existing library is kept.

**Smart App Control:** [windows-smart-app-control.md](https://github.com/samwe20/Folio/blob/main/docs/windows-smart-app-control.md)

## Folio 1.0.10 — Windows

**Instalátor:** [Folio_1.0.10_x64-setup.exe](https://github.com/samwe20/Folio/releases/download/folio-1.0.10/Folio_1.0.10_x64-setup.exe)  
**Požadavky:** Windows 10 nebo 11 (WebView2)

### Co je nového oproti 1.0.8

- **Náhled lokálních obrázků** — oprava načítání souborů z knihovny (`assets/…`) přes Tauri asset protokol; doplněné mapování cest po přetažení screenshotu z Průzkumníka.
- **Aktualizace** — zarovnaná tlačítka *Stáhnout* / *Později* v liště nabídky aktualizace.

**Poznámka:** Release **1.0.9** měl rozbitý náhled obrázků — nepoužívat; použijte **1.0.10**.

### Instalace / upgrade

1. Stáhněte `Folio_1.0.10_x64-setup.exe` ([release folio-1.0.10](https://github.com/samwe20/Folio/releases/tag/folio-1.0.10)).
2. Spusťte instalátor (knihovna v Dokumentech zůstane).
3. Nebo **☰ → Zkontrolovat aktualizace → Stáhnout**.

**Smart App Control:** [windows-smart-app-control.md](https://github.com/samwe20/Folio/blob/main/docs/windows-smart-app-control.md)

## Folio 1.0.10 — Windows (English)

**Installer:** [Folio_1.0.10_x64-setup.exe](https://github.com/samwe20/Folio/releases/download/folio-1.0.10/Folio_1.0.10_x64-setup.exe)  
**Requirements:** Windows 10 or 11 (WebView2)

### What's new since 1.0.8

- **Local image preview** — library files under `assets/` load correctly (Tauri asset protocol + scope); better path repair after Explorer drag-and-drop.
- **Updates** — aligned *Download* / *Later* buttons in the update bar.

**Note:** Release **1.0.9** had broken image preview — do not use; install **1.0.10**.

### Install / upgrade

1. Download `Folio_1.0.10_x64-setup.exe` ([folio-1.0.10](https://github.com/samwe20/Folio/releases/tag/folio-1.0.10)).
2. Run the installer (your library is kept).
3. Or **☰ → Check for updates → Download**.

**Smart App Control:** [windows-smart-app-control.md](https://github.com/samwe20/Folio/blob/main/docs/windows-smart-app-control.md)

## Folio 1.0.8-rc.2 — Windows (pre-release)

**Pre-release test build** for the upcoming **1.0.8** line. Production users on **1.0.7** should stay on [folio-1.0.7](https://github.com/samwe20/Folio/releases/tag/folio-1.0.7) until **1.0.8** stable is published.

**Instalátor:** [Folio_1.0.8-rc.2_x64-setup.exe](https://github.com/samwe20/Folio/releases/download/folio-1.0.8-rc.2/Folio_1.0.8-rc.2_x64-setup.exe)

### Změny v tomto rc (oproti 1.0.7 / dřívějšímu 1.0.8)

- Opravy **dropu obrázků** (Windows), **anglický tutoriál** / migrace české ukázkové knihovny
- **Updater** — hláška „žádná nová aktualizace“, opravené tlačítko *Rozumím*
- V menu aplikace vidíte přesně **`1.0.8-rc.2`**

### Instalace

1. Stáhněte instalátor z odkazu výše (sekce **Pre-release** na [Releases](https://github.com/samwe20/Folio/releases)).
2. Toto **není** finální 1.0.8 — další opravy = `1.0.8-rc.3`, ne `1.0.9`.

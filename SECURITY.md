# Bezpečnost

Markdown náhled prochází [DOMPurify](https://github.com/cure53/DOMPurify) (viz testy v `tests/regression.cjs`).

Bezpečnostní problém prosím **nereportuj ve veřejném issue**, pokud jde o zneužitelnou zranitelnost. Napiš na GitHub účet [samwe20](https://github.com/samwe20) soukromě nebo použij GitHub Security Advisories, pokud jsou pro repo zapnuté.

Pro běžné bugy v chování aplikace použij [issue šablonu](.github/ISSUE_TEMPLATE/bug_report.yml).
